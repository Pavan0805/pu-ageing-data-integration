# Polyurethane Ageing – Data Integration Framework


## Motivation
The project addresses the challenge of handling large, heterogeneous datasets (e.g. thousands of FTIR spectra, GC-MS, mechanical tests data) by introducing structured metadata and automated preprocessing pipelines as a foundation for further statistical analysis or machine learning.

## Scope
- Data integration and metadata design
- Automated FTIR preprocessing and feature extraction
- Reproducible analysis workflows

## Repository Structure
- `/data` – metadata templates and example files  
- `/scripts` – ingestion, preprocessing, and feature extraction scripts  
- `/config` – configuration files (processing parameters and logical paths)
